# Security policy

This repository is Frontier Health's internal fork of
[Maccy](https://github.com/p0deje/Maccy), hardened for staff Macs that handle
regulated data.

## Reporting a vulnerability

Please report vulnerabilities in this fork privately. Do not open a public
issue or pull request.

Use GitHub's private vulnerability reporting: go to the **Security** tab of
this repository and choose **Report a vulnerability**
(<https://github.com/Frontier-Health/Maccy/security/advisories/new>).

Include the affected version or commit, steps to reproduce, and the impact you
expect. If the issue involves real patient or customer data, describe it
without including that data.

## Upstream issues

If a vulnerability exists in upstream Maccy and is not specific to our changes,
report it to the upstream maintainers at <https://github.com/p0deje/Maccy>
following their own process, after telling us here so we can mitigate it on
staff Macs. Issues filed on this fork are not forwarded upstream.
